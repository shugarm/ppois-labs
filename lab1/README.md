# Лабораторная работа №1. Основы ООП: разработка класса

Реализованы два варианта на C++17:

* **1.5.2 Пятнашки** — класс `fifteen::FifteenPuzzle` + консольное меню `fifteen::FifteenMenu`;
* **1.8.1 Машина Поста** — классы `Tape` (лента), `Carriage` (каретка), `Rule` (правило),
  `Program` (программа), `PostMachine` (машина) + меню и консольное приложение.

## Структура

| Папка | Содержимое |
|-------|-----------|
| `include/`  | заголовочные файлы (объявления классов, Doxygen-комментарии) |
| `src/`      | реализация классов |
| `apps/`     | точки входа `fifteen` и `post_machine` (только вызывают библиотеки) |
| `tests/`    | модульные тесты GoogleTest |
| `examples/` | примеры программ для машины Поста |

Логика классов не зависит от консоли: меню получают потоки `std::istream`/`std::ostream`
и вызывают только публичные методы классов.

## Сборка и тесты (из консоли)

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build --output-on-failure
```

## Запуск

```bash
./build/fifteen                                   # игра «Пятнашки» с меню
./build/post_machine examples/add_one.txt         # выполнить программу
./build/post_machine examples/add_one.txt -log    # + состояние после каждого правила
./build/post_machine examples/add_one.txt -i      # интерактивное меню
```

В Windows консоль нужно переключить на UTF-8: `chcp 65001`.

## Формат файла машины Поста

```
# комментарий
tape: 111          # лента: 1 — метка, 0 — пусто; можно указать начало: -2:101
carriage: 0        # номер ячейки под кареткой
program:
1 R 2              # <номер> <команда> [переходы]
2 ? 1 3
3 V 4
4 !
```

| Команда | Действие |
|---------|----------|
| `V j` | поставить метку, перейти к правилу `j` |
| `X j` | стереть метку, перейти к правилу `j` |
| `L j` / `R j` | сдвинуть каретку влево / вправо, перейти к `j` |
| `? j1 j2` | если ячейка помечена — к `j1`, иначе к `j2` |
| `!` | остановка |

Выполнение начинается с правила с наименьшим номером. Постановка метки на помеченную
ячейку и стирание метки с пустой — ошибка выполнения (так определена классическая машина Поста).
